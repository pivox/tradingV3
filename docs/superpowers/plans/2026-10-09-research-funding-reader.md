# Verified research funding reader and continuity inventory

This is a pure data-reader prerequisite of the approved shared-portfolio campaign, not a new source of trading authority. Add `app.backtesting.research.funding` and focused tests. No network, secrets, database or exchange calls.

## Inputs and outputs

- Explicit existing acquisition root, optional source-complements root, selected approved symbols and exact `[start,end)` UTC window. Read immutable manifests privately with bounded, no-symlink/no-traversal regular-file checks. Freeze manifest raw SHA and source identities in the returned inventory.
- Revalidate selected official funding ZIP bytes against both their retained checksum sidecar and manifest SHA; verify the expected fixed source URL/member/size. Reuse binance_history primitives where possible, but emit actual CSV timestamp, signed decimal rate and declared interval hours (the current parser summary alone discards these fields). Reject malformed/duplicate/out-of-order/nonfinite records and excessive expansion. Use bounded per-month storage/streaming, no full candle dataset load.
- Read public API supplement only when its fixed symbol/window/URL/status/raw-page SHA/canonical status_hash bind to the retained successful response. Revalidate every selected JSON observation from raw page bytes and verify equality with indexed observations, chronological paging and source status. Preserve millisecond timestamps and optional positive observed markPrice; never normalize away jitter or silently overwrite an archive observation. Reject duplicate/conflicting overlapping sources unless an explicit exact-byte/provenance policy is tested; no implicit deduplication that hides conflicts.
- Return immutable funding events with timestamp, symbol, Decimal signed rate, optional observed mark, declared interval when present, and source/raw/record hashes. Provide a reusable one-pass iterator and a small bounded quality inventory with counts and first/last observations per symbol; events ordered by time and approved-universe priority. Caller merges these with candle boundaries; do not settle PnL here.

## Coverage policy

- Retain `observed_only` as the provenance level: pagination/archives do not magically certify historical funding completeness. Missing archive/tail/raw evidence is not zero funding. Every requested subwindow must have successfully acquired evidence coverage; no partial run may claim a complete schedule.
- Offer an explicitly named continuity diagnostic based on the CSV declared interval and actual successive timestamps, including monthly joins. Check whether the *current* declared interval matches the elapsed duration within a frozen **1000 ms diagnostic tolerance**, recording the actual jitter rather than altering timestamps. A tolerance is a research QA hypothesis, not an API guarantee. Interval changes must not be flattened to eight hours.
- Real data evidence: SOL November2022 has165 observations, with64 interval8h,99 interval2h,2 interval4h; all other observed campaign archive totals differ accordingly. Inspect this small local archive read-only to settle interval-transition interpretation; if actual transitions do not match the proposed comparison, report the mismatch and conservative alternative before coding an exception. No holdout signals/PnL are read by this data QA.
- First/last boundary diagnostics use declared interval evidence from nearby available observations (load at most adjacent selected monthly archives for context if needed and bind them separately). Do not simply demand a payment exactly at a start/end: rates can occur at +1ms. Clearly separate absent boundary context from a confirmed gap.
- REST tail lacks declared interval metadata. Require an explicit caller-selected hypothesis for diagnostics (e.g. last declared archive interval carried forward), name/hash it, and label resulting continuity `assumed_interval`, not observed metadata or historical attestation. No hidden8h default; unchanged source status/coverage labels. If there is no prior declared interval, remain inconclusive. Trade simulation must receive the quality inventory and decide fail-closed/inconclusive, never silent funding-free operation.
- Actual quote settlement stays the kernel's responsibility: observed markPrice if usable at that timestamp or a declared past-known candle mark proxy; no future mark selection here.
